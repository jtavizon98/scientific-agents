\chapter{Make It Yours}\label{ch:yours}

These skills are one person's working style, built during a physics thesis. They are
meant to be taken apart. This chapter says how to adapt them without losing what makes
them useful: rules that live in one place and reach every agent you use.

\section{Start small}

\begin{headline}
  Install the whole \code{skills/} folder, because the skills link to each other, but
  begin by calling only three.
\end{headline}

\section{Keep your settings in an overlay}

\begin{headline}
  Do not edit a shared skill to record where your files are or who approves a cleanup.
  Keep those facts in one personal file and let the skills say ``the user'' and ``the
  project''.
\end{headline}

The personal file sits next to your project's agent instructions, for example
\code{PERSONAL.md}. Table~\ref{tab:yours-owners} shows where each kind of rule belongs.

\section{Let lessons reach the file that owns them}

\begin{headline}
  A rule that nothing enforces is the first to be forgotten. Route lessons to their owner

\section{Choose how much to delegate}

\begin{headline}
  The default here is to decide, record and report (Chapter~\ref{ch:decisions}). Which
  actions count as reversible depends on your project.
\end{headline}

Agents proceed on reversible work and on defensible scientific defaults, and every
default stays visible until you review it. If your branches are shared, or your review
inbox is a shared folder, say so in your overlay and the gates move accordingly
\cite[Decide, record, report]{skill:actions}.

\section{Stay current without being dragged along}

You can take the skills in two ways:
\begin{itemize}
  \item \textbf{follow:} install the repository as a plugin and follow it;
  \item \textbf{own:} copy the skills you want and own them, recording the commit you copied
        from.
\end{itemize}
This repository does the same for the skills it adapted from others: each records its
upstream commit, and a weekly job opens an issue when an upstream changes. Adopting a
change is then a reviewed edit, not an automatic update.
