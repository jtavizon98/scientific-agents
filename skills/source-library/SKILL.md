# Source library

Read [the owning workflow](../../workflows/source-library.md). Locate the user's
existing bibliography and citation conventions before making a new library.

Identify a source by its inspected edition, not just its title or URL. Reuse an
existing key when it names the same source; preserve specifically cited older
versions. Verify conflicting metadata against the source. Never invent a DOI,
author, date or pinpoint to make a bibliography complete.

Update the shared owning entry, then the affected citations. Keep passage
locators beside claims, including claims in captions and tables. Register local
evidence collections when they are independently citable, with member pinpoints
and a provenance manifest; do not register every intermediate file.

Check global key/shorthand uniqueness, cited-key resolution, metadata and
claim support separately. Build the affected reports with their actual backend
and inspect linked citations and bibliography backreferences. Report unavailable
sources or missing build tools as unverified, not passing. A local wording patch
does not require migrating an otherwise working older citation system.
