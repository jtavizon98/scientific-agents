# Talks and posters

A talk or poster from your own work, someone else's paper or a study in
progress, including a re-cut of an existing deck. Details are in
[presentations](../../presentations/SKILL.md).

1. Name the audience, the slot and the one question, and say which kind of
   talk this is: own work, re-cut, paper, group-meeting update or poster.
2. Read the source material in full: the accepted report or `RESULT.md` and
   the plotbook, the paper, or the existing deck. Ask
   [teach](../../teach/SKILL.md) for what the presenter does not know yet.
3. Write the storyline with every field of the storyline contract. Get the
   presenter's confirmation; record your own choices in it as agent defaults.
4. Build from the template, with speaker notes on every content frame. Reuse
   the reviewed figures; add no claim the written work does not support.
5. Walk the presenter through the frames they did not draft until they can
   defend each one, and rebuild with what it adds. If they are away, record
   the walk-through as pending.
6. Build the audience PDF and the presenter copy. Run the render gate with
   `--profile slides` and fix blocking findings in the source
   ([render-review](../../render-review/SKILL.md)).
7. Review in separate tracks: frames at projection size through an economy
   visual route, and the storyline and notes by a copy reviewer when others
   will judge the talk; check the storyline's rubric map when it is graded.
8. Export the PowerPoint copy if the storyline lists it, deliver to the user's
   review inbox if the project has one, and say what awaits the presenter's
   review.
